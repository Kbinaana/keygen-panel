Validate Key

Check if a key is authentic and active

Quick Validate via URL

Append ?key=YOUR_KEY to the page URL to auto-validate

https://kbinaana.github.io/keygen-panel/?key=YOUR_KEY_HERE

🔌 API Reference

Validate keys programmatically from your app

REST API Endpoint

GET https://keymaster-api.onrender.com/api/validate?key=<KEY>&format=json

Deploy your own server with server.js from this repo! Railway, Render, or any VPS.

Response Format

{
  "valid": true,
  "status": "active",
  "key": "ABCDE-FGHIJ-KLMNO-PQRST-XXXX",
  "user": "gamer123",
  "expiresAt": "2026-12-31",
  "checkedAt": "2026-06-12T12:00:00Z"
}

cURL Example

curl "https://kbinaana.github.io/keygen-panel/?key=ABCDE-FGHIJ-KLMNO-PQRST-XXXX&format=json"

JavaScript / Fetch

fetch('https://kbinaana.github.io/keygen-panel/?key=ABCDE-FGHIJ-KLMNO-PQRST-XXXX&format=json')
  .then(r => r.json())
  .then(data => console.log(data));

Python

import requests
r = requests.get('https://kbinaana.github.io/keygen-panel/', params={'key': 'ABCDE-FGHIJ-KLMNO-PQRST-XXXX', 'format': 'json'})
data = r.json()
print(data)

Node.js

const res = await fetch('https://kbinaana.github.io/keygen-panel/?key=ABCDE-FGHIJ-KLMNO-PQRST-XXXX&format=json')
const data = await res.json()
console.log(data)

Webhook / Auto-Validation
